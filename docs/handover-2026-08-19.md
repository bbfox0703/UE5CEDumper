## D. The sync point, stated plainly

**Your second PC runs `dist` 1.0.0.3262 and should stay there until you install this build.** The
build produced by this session is **1.0.0.3263**, and it is what both machines move to.

⚠ **3262 was deliberately skipped, and here is why it matters.** By the end of the session the
number `3262` named **three different binaries**: the AOT build on your second PC, a **non-trimmed
106.8 MB** `UE5DumpUI.exe` that a plain `build.ps1` had silently written into local `dist/`, and
whatever the next publish would have produced. Reusing it would have broken the one rule that makes
cross-machine debugging possible — *compare a DLL's build against `dist`*. So the counter was moved
past it and **3263 is the first release number that means exactly one artifact.**

⚠ **Amended 2026-08-20 — 3263 now names two DLL binaries.** `dist/UE5Dumper.dll` and the four
`dist/proxy/*.dll` were **rebuilt** that day for the PEHOOK step-3b experiment: identical source,
same sizes, **different bytes**. `dist/UE5DumpUI.exe` was *not* touched and is still the handed-over
54.7 MB AOT binary. Consequence: `tools/verify/proxy_refresh.py` reports **all nine deployed proxies
STALE, and that is a FALSE ALARM** — do not refresh on it.

Two build facts corrected while doing this, because both were written down wrongly:

- **Every `build.ps1` invocation bumps `build_number.txt`** — not just `-Mode Publish`. The bump is
  unconditional at `build.ps1:446`, before any `-Mode`/`-Target` branch. Use `-NoBumpBuildNumber` to
  suppress it. (`docs/working-lessons.md` §7 already had this right; the project memory did not.)
- **A plain `build.ps1` overwrites `dist/`** with the non-trimmed exe. `dist/` is not a
  publish-only output, so "there is a build in `dist/`" never implies "there is a *shippable* build
  in `dist/`". Check the size: **~54 MB = AOT-trimmed and shippable, ~107 MB = must not be handed
  over.** This build's `dist/UE5DumpUI.exe` is **54.7 MB**.

- **`[VOLUMEROOT-2026-08-19]`** — three sites ask `Path.GetPathRoot` + `DriveInfo` about a path and

- **`[SCANIDENTITY-2026-08-19]`** — value-scan candidates are re-read across refines by raw address
