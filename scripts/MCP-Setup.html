UE5CEDumper — MCP Setup

UE5DumpUI.exe --mcp turns the UI's exe into a Model Context Protocol (MCP) server. An AI client such as Claude Code or Claude Desktop starts it and talks to it over stdin / stdout; the AI can then look through a running game the way you do in the UI: find objects, read their fields and class layouts, follow pointers, and run value scans.

Started with --mcp, the exe opens no window. The AI client starts it and stops it.

This version only reads. It never writes game memory, calls a game function, or turns a feature on. Every reading tool's name starts with read_; the one other tool, scan_start, starts the object scan on a game whose scan has never run.

1. What you need

  • A game running UE5Dumper.dll — deployed as a proxy DLL, injected from the UI, or injected through the Cheat Engine table (see README.html).
  • UE5DumpUI.exe from the same release as the DLL. An older DLL answers newer commands with "Unknown command"; the read_status tool says when the two builds differ.
  • An MCP client. The examples below are for Claude Code and Claude Desktop; any client that starts a local (stdio) server works the same way: command UE5DumpUI.exe, argument --mcp.

2. Register the server

Use the full path to UE5DumpUI.exe; the examples use C:\Tools\UE5CEDumper\.

Claude Code

For every project of yours (--scope user), or only the current one (--scope local):

claude mcp add --scope user ue5cedumper -- "C:\Tools\UE5CEDumper\UE5DumpUI.exe" --mcp

Check it: claude mcp list should show ue5cedumper ... ✓ Connected, and /mcp inside a session shows its tools. A session started before the server was added does not see it: start a new one. To remove it: claude mcp remove ue5cedumper -s user.

Claude Desktop

Add it to %APPDATA%\Claude\claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "ue5cedumper": {
      "command": "C:\\Tools\\UE5CEDumper\\UE5DumpUI.exe",
      "args": ["--mcp"]
    }
  }
}
Updating to a new release: each AI session keeps the server running while it is open, and Windows does not let a running exe be replaced. Close the AI sessions (or Claude Desktop) before copying a new UE5DumpUI.exe over the old one.

3. Permissions (optional)

Claude Code asks before each tool call. To let the reading tools run without asking, add one allow rule to your Claude Code settings.json:

{ "permissions": { "allow": ["mcp__ue5cedumper__read_*"] } }

In the default permission mode, scan_start still asks first. In auto mode, Claude Code decides on its own and may run scan_start without asking.

4. Using it

  1. Start the game with the DLL, and load into the game world.
  2. Ask the AI about the game. It calls read_status first. A game loaded through a proxy DLL needs its object scan before anything else answers; the AI can start it with scan_start.
  3. With several games running the DLL, the AI lists them (read_games) and names the game's pid on every call.

Beside the UI. The server and UE5DumpUI.exe are separate processes and can run together; the AI's work never ends or slows down yours:

  • each server has its own connection to the game (the DLL serves 6 at once; the UI uses 2);
  • value scans belong to the connection that started them;
  • the AI's heavy walks take at most half of the free threads, so a value scan or snapshot you start in the UI meanwhile keeps the other half;
  • the server leaves out every command that changes state another program uses.

The UI does not show what the AI read.

A game running as administrator

Windows refuses a program that is not elevated the pipe of a game running as administrator. Start the AI client elevated too, or start the game normally. The server says so when it happens.

5. Using it from another machine over SSH

An MCP client can start the server on the game's PC through SSH: the server runs there and talks to the local pipe, so the pipe never faces the network. Register this as the client's command (example for Claude Code):

claude mcp add --scope user ue5cedumper -- ssh -T user@game-pc "C:\Tools\UE5CEDumper\UE5DumpUI.exe" --mcp
  • -T (no terminal) is required: a terminal would alter the protocol's bytes.
  • Use key authentication. stdin carries the protocol, so SSH cannot ask for a password, and a Windows Hello PIN is never accepted by SSH. For an account in the Administrators group, Windows OpenSSH's default configuration reads the public key from C:\ProgramData\ssh\administrators_authorized_keys, which must be writable only by Administrators and SYSTEM.
  • An administrator's SSH session runs elevated, so a server started that way also reaches a game running as administrator.

Setting up an SSH server on the game's PC (reference only)

For reference only. The commands below are one way to enable the OpenSSH server that ships with Windows 11. They may not work on your machine, and each machine needs its own adjustments: another Windows edition or policy, a firewall, a third-party SSH server instead. Setting up an SSH server is outside the scope of this project.

In a terminal run as administrator:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

The last line starts the server with Windows; leave it out to start it by hand when needed.

6. When something goes wrong

The AI reportsWhat to do
"No game is running the UE5Dumper DLL"Start the game with the proxy deployed, or inject the DLL.
"The game is not scanned yet"Load into the game world; the AI can then call scan_start.
"The game's object scan is still running"Wait: the scan validates its offsets before object tools answer.
"The game's scan finished without finding the object pool"Run Extra Scan in the UE5DumpUI window.
"Several games run the UE5Dumper DLL: pass pid on every call"Tell the AI which game; it names its pid on every call.
"Only an old UE5Dumper DLL's pipe is up"Close the game, run Update All on the Proxy Deploy tab, start it again.
"Every connection to game N's pipe is taken"Close a program holding one; the message names them.
"Windows refused the connection to game N: the game runs as administrator"Start the AI client elevated, or the game normally.
"... did not answer within N s"The game is paused, loading or very large; the next call reconnects.
The client shows the server as failedCheck the path to UE5DumpUI.exe, and that this file is not blocked by antivirus.

The server's log: %LOCALAPPDATA%\UE5CEDumper\Logs\UE5DumpUI\mcp-<date>-<time>-<pid>.log, one file per server; files older than 21 days are deleted.
