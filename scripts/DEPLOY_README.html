UE5CEDumper — Quick Start

UE5CEDumper is a live inspector for Unreal Engine games (UE4.18 – UE5.8). It injects a DLL into the game process, then communicates with a standalone UI via Named Pipe.

Injection Methods

There are a few ways to get UE5Dumper running inside the game process. Use one at a time. If you're not sure, Option C (inject into a running game) is the quickest — no Cheat Engine, no pre-deployed proxy, no game restart.

Option A: Cheat Engine Injection

Best for: CE power users who want full CE integration (Structure Dissect, memory editing, Lua scripting).

Required files: UE5Dumper.dll, UE5CEDumper.CT, UE5DumpUI.exe

  1. Open Cheat Engine and attach to the game process.
  2. Load a save / reach gameplay so UE objects are populated.
  3. Open UE5CEDumper.CT (File > Open).
  4. Enable init <== enable after process attached, then Inject DLL + Start Pipe Server.
  5. Wait a few seconds for the AOB scan to finish.
  6. Launch UE5DumpUI.exe and click Connect.
CE-specific extras: With CE injection, you can also use ue5_dissect.lua to generate CE Structure Dissect entries from UE class reflection. See the CE Scripts section below.

Option B: Proxy DLL (No Cheat Engine)

Best for: users who don't need CE, or when CE causes compatibility issues with the game.

Required files: one proxy DLL — version.dll, dxgi.dll, or dinput8.dll (all in proxy\) — plus UE5DumpUI.exe. The Proxy Deploy tab in the UI can pick the type and deploy it for you per game — it detects Steam games, or scans chosen drives for UE games installed anywhere (Epic / GOG / manual). Four names ship (version.dll / dxgi.dll / winmm.dll / dinput8.dll) so you have a spare when one is already taken.

  1. Copy one proxy DLL (start with version.dll) into the game's root folder (next to the game .exe).
  2. Launch the game normally. The proxy DLL loads automatically via Windows DLL search order.
  3. Load a save / reach gameplay so UE objects are populated.
  4. Launch UE5DumpUI.exe and click Connect.
  5. Click the Start Scan button in the toolbar. The DLL performs the AOB scan and returns engine data.
  6. Browse objects, find instances, export — same workflow as Option A.
Which proxy DLL? version.dll works for most games. Game launches but the UI never connects — the EXE doesn't import version.dll, so switch to dxgi.dll (every D3D11/D3D12 UE game imports it), winmm.dll, or dinput8.dll. Filename already taken by another tool (e.g. ReShade owns dxgi.dll) — pick a free one. All taken or none work — use DLL injection (Option C). Deploy only one at a time.
Why deferred scan? The proxy DLL loads very early (before the game's main loop), so GObjects/GNames may not be initialized yet. Wait until you reach gameplay so the scan finds valid data.
Removing: To stop using the proxy DLL, delete it (version.dll / dxgi.dll / winmm.dll / dinput8.dll) from the game folder — or use the Proxy Deploy tab's Undeploy, which sweeps every proxy flavour it deployed.

Option C: Inject into a Running Game (UI button or CLI)

Best for: the quickest path — inject into an already-running game with no Cheat Engine, no pre-deployed proxy, and no game restart.

Required files: UE5Dumper.dll + UE5DumpUI.exe (UI), or inject-ue.ps1 (command line). Keep them together (the CLI looks for UE5Dumper.dll next to itself).

From the UI:

  1. Start the game and reach gameplay so UE objects are populated.
  2. Launch UE5DumpUI.exe and open the Proxy Deploy tab.
  3. Click Inject into running game…, pick the game in the process picker, and press Inject.
  4. The UI injects the DLL and auto-connects. If the game runs as Administrator you'll get a UAC prompt to inject elevated — no manual restart.

From the command line (run in the folder that holds UE5Dumper.dll):

.\inject-ue.ps1                 # auto: inject the single running UE game
.\inject-ue.ps1 -List           # list detected UE games
.\inject-ue.ps1 -ProcessId 1234 # inject a specific PID

Then launch UE5DumpUI.exe and click Connect. If the game runs as Administrator, the script auto-relaunches elevated (one UAC prompt).

x64 games only, and single-player / offline use only — like all injection, CreateRemoteThread may be flagged by anti-virus and is blocked/banned by kernel anti-cheat (EAC / BattlEye).

Dual-Injection Safety

If you accidentally have version.dll in the game folder and try to inject UE5Dumper.dll via CE:

  • The second instance detects that the pipe \\.\pipe\UE5DumpBfx already exists.
  • It skips auto-start to prevent conflicts.
  • No crash, no duplicate data — the first instance wins.

Best practice: use one method at a time. Remove version.dll from the game folder when using CE injection.

CE Scripts (Option A Only)

ue5_dissect.lua

A CE Lua module that creates Structure Dissect entries from UE class reflection. Only works when UE5Dumper.dll is injected via CE.

-- In CE Lua Engine (after DLL is injected):
local dissect = dofile("ue5_dissect.lua")

-- Interactive: shows dialog to enter class address or UE path
dissect.createInteractive()

-- By UE path
dissect.createFromPath("/Script/Engine.Actor")

-- Auto mode: CE auto-fills Structure Dissect for any UObject address
dissect.enableAutoCallback()

Features: 25+ UE property type mappings, struct flattening (6 levels), BoolProperty bitmask, Array/Map/Set helpers, UObject header, auto-callback, caching.
